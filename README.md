# Thena Web Chat

A modern, enterprise-ready web chat dashboard interface with integrated chat widget functionality.

## Features

- Clean, modern UI with enterprise dashboard layout
- Interactive charts and data visualization
- Integrated chat widget functionality
- Responsive design for all device sizes
- Customizable widget settings

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Configure the widget settings through the dashboard interface

## Customization

You can customize the appearance by modifying the CSS variables in the `:root` selector.
